# ISB 42403 Web Application Development — Lab 1 (ASP.NET Core MVC)

### ⭐ Unified Project (All 6 Apps in One Project)
* [`WebApplication_Lab1_Wan`](./WebApplication_Lab1_Wan) — Combined ASP.NET Core MVC project containing all 6 Lab 1 applications with a navigation menu.

### Individual Projects
1. **BMI Calculator** — [`BMICalculatorApp`](./BMICalculatorApp)
2. **Temperature Converter** — [`WebApplication_TempConverter`](./WebApplication_TempConverter)
3. **Grade Calculator** — [`GradeCalculator1`](./GradeCalculator1)
4. **Multiple Choice Question (MCQ) App** — [`WebApplication_MCQ`](./WebApplication_MCQ)
5. **Favourite Pet App** — [`WebApplication_FavouritePet`](./WebApplication_FavouritePet)
6. **Electricity Bill Calculator** — [`WebApplication_ElectricityBill`](./WebApplication_ElectricityBill)

## How to Run
1. Open [`WebApplication_Lab1_Wan.slnx`](./WebApplication_Lab1_Wan/WebApplication_Lab1_Wan.slnx) in **Microsoft Visual Studio**.
2. Click the **Play ▶** button to launch the dashboard and test all 6 apps.
